# 心动系统 · 恋爱线设计蓝图

> 目标:把"喜欢一个人、慢慢接近她"的**心动感**做进游戏。
> 原则:**恋爱是承重墙,用主流程去"养"恋爱线**——主体流程一行不改,恋爱线只在现有系统上"加挂钩"。

---

## 一、核心原则

1. **恋爱承重,经营服务**:你开便利屋、接委托、熬夜,为的是离她更近。经营是媒介,不抢方向盘。
2. **用主流程养恋爱线**:跟"养成"一个道理——你照常接她的委托、攒好感、抽到她/重复卡(信物)、手机来往,这些**本来就在做的事,顺带把恋爱线喂大**。**不加任何"恋爱专属任务"**,心动节点是正常玩自然解锁的回报。
3. **主体不大改**:接单锁单制、跑图打卡、疲劳、抽卡、战力养成、引荐、好感数值——全照旧。恋爱线**只读不改**这些,只在它们产出的事件上挂触发。
4. **循序渐进 + 克制**:暧昧不能开局就来,要"挣"很久。锁着的内容 = 渴望 + 神秘感 = 心动引擎。

---

## 二、三个面 · 螺旋上升

恋爱线是把现有三个面**拧成一根螺旋**的连接线:

| 面 | 管什么 |
|---|---|
| **手机**(微信/短信/电话,已做分层) | 日常联系 / 暧昧(活的频道) |
| **她的专属页面**(原养成页改造) | 她是谁 + 你俩全部记录 + 恋爱线地图 + 战力养成(中枢/成就墙) |
| **生活场景**(复用剧场/Story) | 里程碑剧场(被螺旋触发) |

**一圈怎么转:**
```
主流程(接她委托/好感)喂一点
 → 手机解锁深一层(工作消息→私人消息→短信→电话)
 → 在手机上跟她来往,攒「默契」
 → 攒够触发一个【生活场景】(里程碑·剧场演一段)
 → 场景回写:专属页面记一笔 + 好感/关系阶段推进 + 解锁更深手机层
 → 进入下一圈,暧昧更进一步
```
手机+专属页面是"日常的养"(天天一点点),生活场景是"里程碑回报"(攒够才来一次)。**暧昧节奏全程对齐手机分层:工作消息 → 私人消息 → 短信 → 电话,每深一层都得先在生活场景里"成"一件事。**

---

## 三、排他:确认心意门

- **门之前(暧昧期)**:可同时和几个老婆走**浅层节点**(还只是"有点在意")。
- **门那一刻**:要往深走,必须**选一个人确认心意**。
- **门之后(排他)**:只有她能走深层/亲密节点;其他人的深层线**锁住**,慢慢"好友化"、渐行渐远(有人会失落、退出)。

→ 专注一人有意义、选择有代价、错过有遗憾。这才是"喜欢一个人"的重量。

---

## 四、她的专属页面 = 渐进解锁的成就墙 + 路线图

原养成页(CharacterDetail)从"刷数字面板"重做成**她的专属主页**。入口/路由不变(主体不动),内容重做。

**关键:不是一开始全摊开,是逐格解锁。** 锁着的格子既勾人(心痒)、又指路(下一步)。既是回看墙,又是路线图。

三块:

**① 档案(她的资料)** — 渐进揭开
描述、表情、属性、她的世界观小料。**越靠近越懂她**——深层资料锁住,到对应心动节点才翻开("原来她一紧张就反复核清单")。

**② 我们的故事(核心 · 全部记录)** — 情感重心
- **心动线**:生活场景节点路径(已过/锁住/下一个),每个"下一个"带**指引**(怎么挣到,不剧透内容)。
- **共同经历**:为她完成过的委托、解锁的 CG/视频(锁着=剪影)。
- **重要时刻时间线**:入伙、面试通过、闸机口……里程碑串成一条线,逐步填满。
- 关系阶段在此**只读展示**,由心动线节点推进,不再是按钮。

**③ 培养(她作为搭档 · 战力)** — 保留
等级、经验、被动效果、灵石升级(已接进主循环那套)。这是"她多能打",经营轴。

**砍掉**:触摸/对话/送礼"点一下+好感"、关系阶段"点按钮升阶"——空洞且与手机/恋爱线撞车。
→ 好感改由**玩主流程 + 手机来往**自然涨;关系阶段由**心动线节点**推进。
→ 手机分层用的是好感**数值**门槛(不依赖升阶按钮),所以砍按钮不破坏任何现有玩法。

## 五、江夏 · 慢热五相位(首条垂直切片)

她的人设钩子:认真到笨拙、紧张、靠列清单稳住一切。这条线 = **她一点点卸下"清单铠甲",敢把没整理好的慌乱交给你**。

| 相位 | 手机 | 专属页面 | 生活场景(里程碑) |
|---|---|---|---|
| **一 共事** | 只工作消息 | 大半锁住·档案只露表层 | ①搭档第一天(纯共事·零暧昧) |
| **二 熟络** | 解锁第一条私人消息 | 解锁日常对话·档案翻一条 | ②加班的闲聊 |
| **三 暧昧** | 短信解锁·半夜没头没尾一条 | 她开始躲闪·档案露软肋 | ③清单上的胖大海(第一次心跳) |
| **四 告白门** | —— | 关系阶段卡在门前 | ④闸机口·确认心意 → 排他锁定 |
| **五 深耕→终幕** | 电话接通·煲粥 | 亲密·专属称呼 | ⑤没整理好的清单 → 两个人的清单 + CG |

### 节点①(纯共事,零暧昧)— 开场调子
- **解锁(全是已在做的)**:接过她委托 ≥1 次 + 已加微信 + 跑完一趟回店打烊。
- **一场戏**:她当后勤搭档头一天,准备过头、紧张数错一箱货、慌忙道歉、靠清单稳住自己重数对。你看到的只是认真到笨拙、容易慌、但靠谱的同事。
- **你的选择(喂隐藏「默契」)**:调侃啰嗦 / 安慰别慌 / 放手让她自己稳——都是共事分寸。
- **她的回应**:松一口气"原来你不嫌我麻烦",职业信任萌芽。手机上发的还是工作消息「明天的物资我列好了,你过目下」。

### 暧昧节点(相位三才到)
胖大海纸条、调侃"我排第几"等**第一次心跳**的内容全在相位三,且连她自己都没想明白。

## 六、引擎 & 数据(只加挂钩)

- **数据**:`romanceArcs.json`,每人一串节点 `{id, 相位, 触发条件, 一场戏(剧场ref或内联), 选项[改默契/flag], 她的回应/解锁(手机层/档案条目/CG)}`。内容化。
- **触发**:复用 `conditionEngine`(evaluateAll),读「委托完成/好感/flag/默契/没冷落」等**现有事件**。
- **演戏**:复用 `CommissionTheater` / `DialogueBox` / `Story`。
- **回报**:接手机系统(她发消息/接电话)+ 视频/CG + 专属页面记录。
- **store 新增字段**(加版本号 + migrate,老存档平滑):
  - `romanceProgress: Record<charId, 当前节点>`
  - `xinyiTarget: charId | null`(确认心意选了谁)
  - `momo: Record<charId, number>`(隐藏默契值,由选项喂)
  - 解锁记录(档案条目/CG/时间时刻)flag 化,复用 flags。
- **排他规则**:`xinyiTarget` 锁定后,其他人过门后节点全锁,触发"好友化/退出"。

---

## 七、开工顺序

1. **引擎 + schema + store 字段 + 排他锁**。
2. **江夏 相位一(共事)+ 节点①**:三面同时跑通(触发→剧场→选择喂默契→她的手机回应→专属页面记一笔)。
3. **专属页面改造**:渐进成就墙 + 心动线视图 + 指引;砍 tap-affinity/阶段按钮,战力养成保留。
4. **闸机口告白门④ + 排他锁定**。
5. 江夏 其余节点 + CG。
6. 验对感觉,**复制另外 7 条**(内容工作)。

> 每个老婆的恋爱线 = 独一无二的内容(挂同一套引擎),都得长在她的身份与软肋上(苏音音=黑暗里的声音让你看见脸;陈小满=横冲直撞学会慢下来;顾夜莺=安抚所有人却没人安抚她……)。
