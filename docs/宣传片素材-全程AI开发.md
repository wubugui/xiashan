## 二、叙事主线：一个想法是怎么长成一款游戏的

这是视频的「故事骨架」，建议按这 6 幕推进。每一幕都给了**真实的项目文字**当屏幕字幕。

### 第 1 幕 · 起点：一个想法

最初的想法是一款修仙题材的线性文字冒险游戏——代号《废物下山》。
项目从一句 `Initial project import` 开始。

> **屏幕字幕**：「一切从一行字开始：Initial project import」
> **旁白**：最初，它只是一个修仙文字游戏的念头。

### 第 2 幕 · 推翻：把自己否定掉

AI 在开发中判断线性 AVG 的可玩性天花板太低，主动提出**推翻重做**——
转向「抽卡 + 跑图办事」的都市便利屋玩法。旧的《废物下山》被整体废弃。

> **设计文档原话（可直接上字幕）**：
> 「本文档为项目唯一现行设计，**取代已废弃的《废物下山》线性 AVG**。」
> 「与已废弃的剧情 AVG 的本质区别：**没有写死的剧情线，所有内容都是『卡 × 场景』的组合**。」
> 「**内容是『加法』录入，可玩性是『乘法』增长**。一次开发，配置续命。」

> **旁白**：开发到一半，AI 推翻了自己——它认为线性剧情走不远，于是把整套玩法重做成了抽卡 Roguelike。
> 这一幕的张力在于「AI 会自我否定」，是全片最有记忆点的转折。

### 第 3 幕 · 立柱：系统一根根长出来

围绕「便利屋老板」的核心幻想，AI 从零搭起了一整套相互咬合的系统。每一个都对应一次真实提交：

| 系统 | 提交记录原文 |
|------|--------------|
| 核心循环 | `feat: 委托板+子目标制+顺手单 — 主循环重做(v1.4)` |
| 抽卡 | `feat: 抽卡双频道重做 — 统一补给池+人物保底` |
| 玩法引擎 | 12 种服务标签 × 场景热点的 type 匹配（最省成本、可无限扩展的核心机制） |
| 叙事演出 | `委托剧场`——图驱动 AVG，剧情是有向图而非线性脚本，按幕穿插进跑图 |
| 角色养成 | `feat: 好感与关系系统 v1.2 实装`（好感独立存储 / 心动 UP / 5 阶关系） |
| 都市外围层 | 手机模拟器：微信 / 短信 / 电话 / 浏览器推送，条件驱动 48 条事件 |

> **旁白**：店开在不存在的「第二十五小时」，专门接住被城市时间表漏掉的人。
> 抽卡、跑图、委托、好感——四套系统互相喂养，没有一行是模板套出来的。

### 第 4 幕 · 进化：四次大改版，越改越好玩

AI 没有停在「能跑」，而是反复推翻细节、重做手感。一次合并里就装进了四个改版：

> **提交原文**：`Merge: 玩法改版四迭代——委托锁单制 / 跑图叙事绑定 / 疲劳值系统 / 缘分图鉴引荐`

- **委托锁单制**：委托永不过期、进度跨天保留——根治「卡关」
- **跑图叙事绑定**：路线感知委托、手机实时催促——跑图不再是空走
- **疲劳值系统**：用单一仪表替代天数双时钟、咖啡递减、主动打烊
- **缘分图鉴 / 引荐**：姐妹互相引荐、好感溢出折碎片

> 画面建议：四个改版做成「版本号跳变 v1.2 → v1.3 → v1.4」的进度条。

### 第 5 幕 · 打磨：把体验抠到像素

最后一天几乎全在打磨手感与演出。这些提交标题本身就是很好的「细节控」字幕：

- `feat: 强制锁定式新手引导——江夏全程解说，19 步固定剧本覆盖核心循环`
- `feat: 抽卡演出三段式重做——蓄力光束 / 冲击帧分管线 / 结算页 cinematic`
- `feat: 抽卡高稀有演出改为剪影揭晓——背景图剪影 → 星星暂停 → 白闪定格`
- `fix: 浮层 / 底栏定位系统化——自动测量取代硬编码`（适配所有手机的安全区）
- `feat: 启动加载屏，预下载全部图片资源` + `资源版本校验——只有资源变动才重新下载`
- `feat: 移除底部导航栏——挡视线，所有页面已有返回与首页入口`

> **旁白**：从抽卡的每一帧白光，到底部按钮在不同手机上差几个像素——AI 自己发现，自己修。

### 第 6 幕 · 成形：连「画」和「声音」也是 AI 做的

最体现「全程 AI」的一幕：连素材生产线本身都是 AI 设计的。

- **8 位女主立绘 + 表情切图 + 头像**：AI 生成设定图，再切出 6 种表情接入运行态
- **配音**：AI 写好了 ElevenLabs 音色设计提示词 + 每人 3 句带演技标签的朗读文本
  > 如苏音音（午夜电台主播）：`[whispers] ……你还在？[soft] 那就别急着挂断。`
- **音效**：`feat: 全游戏音效系统，Web Audio API 合成无版权`——连音效都是代码现场合成的，零版权素材
- **专属影像**：24 段视频的「首帧场景图提示词 + 动效提示词」全部写好，放对文件名即生效

> **旁白**：剧本是 AI 写的，画是 AI 画的，声音是 AI 调的，连音效都是 AI 用代码当场合成的。
