# 可搜集物层级规则

收藏物按关系亲密度递进。越私密、越贴身、越不可公开的礼物，层级越高。

- 一层：日常关照。来自她的职业、习惯或审美，但还可以解释为普通朋友之间的体贴。
- 二层：只给你的偏心。开始出现专属记忆、只对你开放的内容，别人拿不到同款。
- 三层：贴身私物 / 终幕信物。必须意味着玩家和她关系非常近，通常包含私密表达、共同归属或长期承诺。

## 角色顺序

| 角色 | 一层：日常关照 | 二层：只给你的偏心 | 三层：贴身私物 / 终幕信物 |
|---|---|---|---|
| 苏音音 | 零点蓝花蕾丝匣 | 第十三封蓝缎信 | 唯一留声坠 |
| 云晓蔻 | 星糖双马尾夹 | 未公开高光册 | 唯一观众钥匙 |
| 顾夜莺 | 黑羽留灯胸针 | 月相安眠香囊 | 打烊留座钥匙 |
| 许念 | 白蕾丝暖手包 | 慢慢来花种匣 | 两个人的猫铃 |
| 祁宁 | 临时门禁卡 | 决策硬币 | 两个人的流程图 |
| 沈疏桐 | 末页批注 | 搭档徽章 | 专属致谢页 |
| 陈小满 | 留给你的能量棒 | 夜班路线图 | 冲线号码布 |
| 江夏 | 入职窗边下午茶 | 胖大海便签 | 两个人的清单 |

## 设计检查

- 第一件不能过度私密：它是开门礼，承担角色识别和功能引导。
- 第二件必须出现偏心：同类物可以给别人，但这一件只能给玩家。
- 第三件必须有关系重量：送出后应让玩家感觉关系进入不可逆的近距离。
- 背景不能复用同一产品桌：场景要解释礼物来自她生活里的哪个时刻。
